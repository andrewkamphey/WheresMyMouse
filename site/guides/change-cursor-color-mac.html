How to Change Cursor Color on Mac: Fill, Outline, or Both

Updated 2026-10-23 · macOS 12 Monterey to macOS 26 Tahoe

Quick answer: Open System Settings → Accessibility → Display → Pointer. Click the Pointer fill color well to change the inside of the arrow, or Pointer outline color to change its edge, and pick a color. Needs macOS 12 Monterey or later.

The Mac pointer has two colors: the fill (the inside, black by default) and the outline (the edge, white by default). You can change either one, or both. First get to the Pointer settings:

  1. Open System Settings

    Click the Apple menu in the top-left corner of the screen and choose System Settings.

  2. Go to Accessibility, then Display

    Click Accessibility in the sidebar (you may need to scroll down), then click Display.

  3. Scroll down to Pointer

    Scroll to the Pointer section. Everything about the pointer is here: Shake mouse pointer to locate, Pointer size, Pointer outline color, Pointer fill color and Reset Colors.

How to change the cursor fill color

  1. Click the Pointer fill color well

    It's the color swatch next to Pointer fill color.

  2. Pick a color in the Colors window

    A Colors window opens. Click a color on the wheel and drag the slider below it to set how dark it is. The pointer updates right away; close the window when you're done.

How to change the cursor outline color

  1. Click the Pointer outline color well

    It's the swatch next to Pointer outline color.

  2. Pick a color in the Colors window

    Same window as for the fill. A dark outline helps on light backgrounds; a light outline helps on dark ones.

How to change both fill and outline

Set the fill first, then the outline, using the steps above. Pick two colors that contrast with each other, so the pointer stands out on both light and dark backgrounds. Some pairs to try:

FillOutlineGood for
YellowBlackSeeing it on anything, light or dark
WhiteBlackDark mode and dark apps
RedWhitePresenting and projectors
BlueWhiteScreen recordings and tutorials

How to pick an exact color

In the full Colors window, choose the sliders tab and set it to RGB. There you can type a hex code such as #FF3B30, handy for matching a brand color in product videos.

How to change the colors back

Click Reset Colors in the same section. It restores the white outline and black fill. More in how to get your cursor back to normal.

On older versions of macOS

  • macOS 13 Ventura and later (Sonoma, Sequoia, Tahoe): System Settings → Accessibility → Display → Pointer, as above.
  • macOS 12 Monterey: Apple menu → System Preferences → Accessibility → Display → Pointer. Apple's guide for Monterey.
  • macOS 11 Big Sur and earlier: size only. Pointer colors arrived in Monterey.

Why didn't the color change in some apps?

Some apps, often games and some design tools, draw their own cursor and ignore the system pointer settings. The color comes back when you switch to another app.

Questions

How do I change my cursor color on a Mac?

Open System Settings → Accessibility → Display → Pointer, click the Pointer fill color or Pointer outline color well, and pick a color.

What is the cursor fill color?

The color inside the arrow. It's black by default.

What is the cursor outline color?

The color of the arrow's edge. It's white by default.

Can I change the cursor color on macOS Big Sur?

No. Pointer colors were added in macOS 12 Monterey.

How do I reset the cursor color?

Click Reset Colors in the Pointer section of Accessibility → Display.
